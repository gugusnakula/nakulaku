Peran Admin: Pengurus vs Super Admin
Pengurus — kelola operasional harian: guru, pertemuan, verifikasi, award, laporan. Super Admin — semua akses Pengurus + hapus permanen, backup database, transfer super admin. Bab 10–12 khusus Super Admin (ditandai 👑 SA).

Super Admin 👑 SA

Hapus Permanen Guru & Sekolah

Hanya Super Admin yang bisa hapus permanen guru/sekolah. Pengurus hanya bisa nonaktifkan. Sistem punya guardrail untuk mencegah data corruption.

Konfirmasi Hapus
⚠️ Perhatian: Akun yang sudah punya aktivitas (presensi/tugas/feedback) akan dinonaktifkan, bukan dihapus. Hanya akun tanpa aktivitas yang bisa dihapus permanen.
Ketik nama lengkap guru: Budi Santoso
1
Buka Data Guru → klik guru → Hapus / Nonaktifkan.
2
Sistem akan cek aktivitas — kalau ada, guru hanya dinonaktifkan (soft delete).
3
Kalau tidak ada aktivitas → perlu konfirmasi ketik nama persis → hapus permanen.
4
Untuk sekolah — sama, cek dulu semua relasi (guru, prestasi, dll). Kalau ada, sistem sarankan nonaktifkan.
Rekomendasi: Jangan hapus permanen kecuali benar-benar perlu (misal typo/duplikat). Selalu nonaktifkan saja untuk audit trail yang lebih baik.

Super Admin 👑 SA

Tambah & Transfer Super Admin

Kalau perlu tambah SA baru (misal backup), gunakan Kelola Peran di Data Guru. Kalau perlu rotasi SA (SA lama pensiun), pakai Transfer di Pengaturan.

2 Cara Kelola SA
Cara 1: Tambah SA (Backup)
Data Guru → klik user → Kelola Peran → pilih 👑 Super Admin → konfirmasi warning merah.
Cara 2: Transfer SA (Rotasi)
Pengaturan → tab Transfer → pilih user target → ketik nama konfirmasi → transfer. SA lama otomatis turun jadi pengurus.
1
Tambah SA: Data Guru → klik user → Kelola Peran → 👑 Super Admin.
2
Warning merah muncul (akses penuh) → konfirmasi → SA baru aktif.
3
Transfer SA: Pengaturan → Transfer → pilih user → ketik nama persis → transfer.
4
Setelah transfer, login ulang — role lama turun, role baru naik.
Guardrail: Sistem tidak bisa hapus SA terakhir. Minimal selalu ada 1 SA aktif — kalau Anda coba hapus SA terakhir, backend akan tolak dengan pesan error.
SA wajib punya pengurus + peserta agar fully functional. Tanpa pengurus, banyak fitur admin tidak jalan. Tanpa peserta, tidak bisa presensi/kumpul tugas.

Pertanyaan Umum

Kalau panduan di atas belum menjawab, cek FAQ ini dulu

Beda Pengurus dan Super Admin di mana?
Pengurus: operasional harian (guru, pertemuan, verifikasi, award, laporan). Super Admin: semua Pengurus + hapus permanen + backup + transfer SA. Kalau ada 3+ pengurus, biasanya cukup 1-2 SA saja.
Guru tidak bisa login — apa yang dicek dulu?
1) Akun aktif? (Data Guru → lihat badge hijau). 2) Email & PIN benar? Coba reset PIN. 3) Password sudah ganti? Cek "PIN sudah diubah" — kalau iya, minta user login ulang. 4) Browser cache — coba incognito.
Kapan pakai Bulk Action vs Import CSV?
Bulk Action: operasi pada guru existing (reset PIN massal, nonaktifkan, assign peran). Import CSV: tambah guru baru dari file (setup awal, migrasi).
Cara hapus guru yang sudah ada presensi/tugas?
Tidak bisa dihapus permanen — hanya bisa dinonaktifkan. Ini supaya data historis (presensi, award periode lama) tetap utuh. Kalau akun nonaktif login → muncul error "Akun tidak aktif".
Verifikasi luar radius — poin masuk kapan?
Saat admin setujui: presensi tercatat dengan poin 50. Saat tolak: status jadi alfa (0 poin). Guru tidak bisa "presensi ulang" setelah diverifikasi.
Award dihitung otomatis — bisa override manual?
Bisa. Setelah Hitung, Anda bisa set juara manual per nominasi (klik nominasi → tetapkan juara 1/2/3). Formula tetap jalan sebagai saran, tapi keputusan Anda yang final.
Data testing mau direset sebelum publish — bagaimana?
Backup dulu via Pengaturan. Lalu jalankan SQL reset (lihat roadmap). Yang dipertahankan: users, sekolah, peran, ks_sekolah, jabatan, kategori_ajuan, feedback_aspek, pelapor. Yang dihapus: pertemuan, presensi, tugas, feedback, award, dll.
Kenapa KS tidak bisa akses admin/index.html?
By design. KS pakai menu khusus di beranda (Sekolahku + Verifikasi), bukan Admin Panel. Kalau KS coba akses, backend tolak. Ini mencegah KS "salah masuk" ke fitur yang bukan wewenangnya.
Berapa maksimal Super Admin yang sehat?
1-3 SA. Lebih dari 3 sulit audit (siapa ubah apa). Ideal: 1 SA utama + 1 SA backup (jaga-jaga kalau SA utama tidak aktif).
Kalau salah hapus permanen, bisa recover?
Tidak bisa via UI. Recovery hanya via Supabase → Database → Backups (backup harian otomatis, retention 7-30 hari tergantung plan). Karena itu, backup mingguan + hindari hard delete sangat disarankan.
Import CSV banyak guru — ada batas?
Batas upload ke Edge Function ~ 500 baris per batch. Kalau lebih, pecah jadi 2-3 file. Setiap batch tercatat di impor_log — bisa audit siapa import kapan.
Lupa PIN admin sendiri?
Minta admin lain reset via Data Guru. Kalau Anda satu-satunya admin, hubungi Super Admin. Kalau Anda satu-satunya SA dan lupa PIN — reset manual via Supabase SQL (generate hash baru) atau restore dari backup.

Siap Kelola NAKULAKU?

Login sebagai admin dan mulai operasikan sistem. Kalau ada kendala, koordinasi dengan sesama pengurus.
